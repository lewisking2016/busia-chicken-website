DEPLOYMENT STEPS:

1. Upload all files to cPanel public_html directory
2. Create database and run schema.sql
3. Update Backend/config/database.php with live credentials
4. Create necessary directories with permissions:
   - /assets/images/uploads (755)
   - /logs (700)
   - /tmp (700)
5. Configure .htaccess for URL rewriting
6. Set up SSL certificate
7. Test all functionality
8. Monitor error logs
9. Set up backup schedule

FILE PERMISSIONS:

/config/database.php - 640 (readable by web server, not public)
/logs/ - 700 (not accessible from web)
/assets/images/uploads/ - 755 (writable by server)
All other files - 644 (readable by everyone, writable by owner)

.HTACCESS CONFIGURATION:

The project needs .htaccess for:
- URL rewriting (clean URLs without .php)
- GZIP compression
- Browser caching
- Security headers

Create .htaccess in root with rewrite rules.
