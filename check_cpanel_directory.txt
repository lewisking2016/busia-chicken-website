CPANEL DIRECTORY CLEANUP INSTRUCTIONS
=====================================

Your cPanel is complaining because the directory contains hidden files.
Even though you moved visible files, hidden files remain.

OPTION 1: SSH into cPanel (Recommended)
----------------------------------------
1. Open SSH terminal in cPanel (Terminal icon)
2. Run these commands:

cd /home/qymwtpra/new.kindcommoditiesltd.com
ls -la

# This will show ALL files including hidden ones like:
# .htaccess
# .git/
# .well-known/
# .cpanel/
# index.html (default)

3. Remove all files (CAREFULLY):

cd /home/qymwtpra/new.kindcommoditiesltd.com
rm -rf * .[^.]*

# This removes all files AND hidden files

4. Verify it's empty:

ls -la

# Should only show:
# .
# ..


OPTION 2: Use cPanel File Manager
----------------------------------
1. Go to cPanel > File Manager
2. Navigate to: /home/qymwtpra/new.kindcommoditiesltd.com
3. Click "Settings" (top right)
4. Check "Show Hidden Files (dotfiles)"
5. Click "Reload"
6. Now you'll see ALL files including:
   - .htaccess
   - .git/ (if exists)
   - .well-known/
   - Any other dot files
7. Select ALL files (Ctrl+A or check the top checkbox)
8. Click "Delete" button
9. Confirm deletion


OPTION 3: Rename and Create New Directory
------------------------------------------
1. Via SSH or File Manager, rename the directory:

cd /home/qymwtpra
mv new.kindcommoditiesltd.com new.kindcommoditiesltd.com.backup

2. Create fresh directory:

mkdir new.kindcommoditiesltd.com
cd new.kindcommoditiesltd.com


AFTER CLEANING, CLONE THE REPOSITORY:
